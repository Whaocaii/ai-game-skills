# 行为验收

| 输入或故障 | 应观察到的结果 |
| --- | --- |
| 空串、emoji、噪声 | 按当前玩法给出完整结果，不偷偷推进 |
| 合法可执行行动 | 状态与反馈一致，按规则推进 |
| 超出角色能力的行动 | 无越权修改，有可理解的反馈 |
| 版本/任务名错误、字段缺失、数值越界 | 丢弃远程结果，验证本地兜底后结算 |
| 同步抛错、Promise reject | 走本地兜底，不悬挂输入锁 |
| 一直不返回 | 到真实时间截止后使用兜底；演出结束才呈现 |
| 超时后远程返回 | 只保留先前结算，迟到值无效 |
| 同时按按钮与回车 | 在途共享同一请求和结算 |
| 等待中重玩或改变状态版本 | 旧结果不修改新状态 |
| 请求函数修改它收到的快照 | 权威状态和验证快照不受影响 |
| 本地兜底也非法 | 显式错误，不推进、不反复请求 |
| 提交函数抛错 | 不重试结算，由宿主处理原子性与恢复 |
| 没有模型服务 | 明确为本地规则示例，不声称语义理解 |

Node 测试使用受控时钟与模拟请求，可证明控制器边界行为。发布具体游戏时还要验证真实键盘/触屏、暂停恢复、错误 UI、模型请求、日志脱敏和服务端状态权限。
