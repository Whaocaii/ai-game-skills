# 长线成长与资源经济

本模块由 Whaocaii 主导设计与维护，使用 AI 辅助编写。当前版本为 0.1.0 工作草稿。按用户的目标与现有项目约束执行；仅使用实际可用的工具。

## 输入

- 成长阶段、资源产消、装备流转和竞争规则
- 玩家活跃周期、付费限制及已有经济数据

## 工作过程

1. 分层记录每天能投入的时间和可接触内容，不把全体玩家当成同一成长速度。
2. 画出资源从产生到消耗、交易、回收的路径，区分系统生成财富与玩家间转移。
3. 强化流程按成功、失败、降级和保护分别计算长期成本；展示失败尾部和止损选择。
4. 检查装备供给随服务器年龄的变化，新玩家追赶不能依赖老玩家已停止参与的唯一来源。
5. 对竞争内容验证领先者是否同时垄断未来成长资源，提出缓解滚雪球的候选规则。

## 交付

- 分层成长路径与产消账本
- 强化成本分布和经济异常观察项

## 检查

- 玩家交易未被当成全服新增资源
- 长期追赶设计不会让早期付出无解释地失效

## 使用案例

开服一个月后低级材料价格暴涨，新玩家无法强化。分析供给退出、回收和追赶方案。

验收时按上面的检查项判断结果；只读完本文件不代表完成了任务。
