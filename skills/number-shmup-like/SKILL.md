# 弹幕压力与火力覆盖

本模块由 Whaocaii 主导设计与维护，使用 AI 辅助编写。当前版本为 0.1.0 工作草稿。按用户的目标与现有项目约束执行；仅使用实际可用的工具。

## 输入

- 视野、移动速度、碰撞体和弹幕路径
- 武器覆盖、敌机耐久、阶段长度和复活规则

## 工作过程

1. 将弹幕威胁分为空间占用、反应时间和路线封锁；弹丸数量本身不是难度指标。
2. 在实际命中覆盖下估算击破时间，处理屏外、无敌、换位和攻击空窗。
3. 检查威胁提示到命中的时间是否容许目标设备上的操作延迟。
4. 比较保守避弹与冒险得分路线，奖励不能强迫所有玩家走极限通道。
5. 验证失误后保护、复活位置和火力损失，避免一次中弹滚成连续必死。

## 交付

- 阶段火力与威胁表
- 可避通道、复活安全区和得分取舍说明

## 检查

- 关键攻击存在可说明的避让窗口
- 掉火力后仍有可恢复的进度路径

## 使用案例

Boss 第二阶段子弹不多却频繁造成无解死亡。分析路线封锁、碰撞体和复活位置。

验收时按上面的检查项判断结果；只读完本文件不代表完成了任务。
